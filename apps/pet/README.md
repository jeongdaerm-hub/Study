# 다로펫 (`apps/pet`)

반려동물 전용 앱. 개발·배포·업데이트 절차는 [루트 README](../../README.md) 참고.

## 기능

| 탭 | 기능 | 세부 |
|---|---|---|
| 🏠 홈 | 펫별 요약 | 오늘 일기 여부, 배변 건강 신호, 다음 일정 |
| 📔 일기 | 일기 작성 | 날짜, 기분, 본문, 사진(최대 5장), 배변 체크(상태·횟수) |
| 🔔 일정 | 일정 + 알림 | 병원/접종/구충제/미용/산책, 미리 알림, 매일/매주/매월 반복 |
| (공통) | 인앱 업데이트 | `@daro/app-core` UpdateGate |

## 배변 건강 신호 (`src/logic/poop.ts`)

| 조건 (최근 7일) | 결과 |
|---|---|
| 혈변 1회 이상 | 🔴 병원 권장 |
| 이상 배변 2일 연속 | 🔴 병원 권장 |
| 이상 배변 1회 이상 | 🟠 관찰 |
| 그 외 | 🟢 정상 |

## 앱 전용 vs 공통

| 앱 전용 (`apps/pet/src`) | 공통 사용 (`@daro/app-core`) |
|---|---|
| 펫 목록, 일기·일정 화면, 배변 분석, 펫 알림 문구 | 업데이트, 알림 예약, 저장소, 사진, 반복 일정, UI |
