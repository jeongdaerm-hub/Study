# 다로펫 (`apps/pet`)

여러 반려동물의 건강·체중·생활·일정을 한곳에서 관리하는 앱. 개발·배포·업데이트 절차는 [루트 README](../../README.md), 보안은 [SECURITY.md](../../SECURITY.md) 참고.

## 화면 구성 (하단 탭 5개)

| 탭 | 기능 | 세부 |
|---|---|---|
| 🏠 홈 | 상태 대시보드 + 오늘 할 일 | 종합 상태(양호/관찰/병원 권장), 오늘 일정 체크, 오늘 식사·음수·배변·구토, 빠른 기록 |
| 🩺 건강수첩 | 진료 · 검사 수치 · 예방접종 | 진료 기록(영수증 사진), 검사지 수치 → 높음/낮음 자동 표시, 다음 접종일 → 일정·알림 자동 등록 |
| ⚖️ 체중 | 날짜별 변화 그래프 | 선 그래프(점 누르면 값), 직전·한 달 변화율, 한 달 10% 이상 변화 경고 |
| 📔 생활일지 | 식사 · 음수 · 배변 · 구토 · 메모 | 날짜별 기록, 하루 합계, 사진 첨부 |
| 🔔 일정 | 접종 · 투약 · 병원 방문 | 미리 알림, 매일/매주/매월 반복, 놓친 일정 표시 |

- 상단 펫 선택 칩으로 **여러 마리 전환**, `＋ 추가`로 등록
- 처음 실행 시 **샘플 데이터(다로·나비)로 둘러보기** 가능

## 📷 사진으로 불러오기 (건강수첩 탭)

| 단계 | 내용 |
|---|---|
| 1. 촬영 | 예방접종 수첩·진료비 영수증·혈액검사지 (최대 3장) |
| 2. AI 판독 | 접종·진료·검사 수치·다음 일정 추출 |
| 3. 확인 | 중복은 기본 해제, 흐린 항목 '확인 필요', 다음 접종일 없으면 '추정' 표시, 항목별 수정 |
| 4. 저장 | 기록 등록 + 다음 접종·내원 일정·알림 + (선택) 지난 진료·접종을 '완료' 일정으로 동기화 |

| 실행 환경 | 판독 방식 |
|---|---|
| 앱 (`DARO_SCAN_API_URL` 설정) | 스캔 서버 → Claude |
| claude.ai 웹 미리보기 | 보는 사람의 Claude 계정 |
| 둘 다 없음 | 예시 결과 (체험용, 화면에 표시) |

## 건강 신호 규칙

| 항목 | 병원 권장 🔴 | 관찰 🟠 |
|---|---|---|
| 배변 (7일) | 혈변 1회 / 이상 배변 2일 연속 | 이상 배변 1회 이상 |
| 구토 | 피 섞인 구토 / 이틀간 2회 이상 | 7일간 3회 이상 (헤어볼 제외) |
| 체중 | — | 한 달 ±10% 이상 |
| 접종 | 예정일 지남 | 14일 이내 |
| 검사 | — | 최근 검사에 참고 범위 밖 항목 |

※ 기록 기반 참고 정보이며 진단이 아님 (앱 화면에도 안내)

## 코드 구조

| 경로 | 내용 |
|---|---|
| `src/types.ts` | 데이터 모델 (펫, 진료, 검사, 접종, 체중, 생활일지, 일정) |
| `src/logic/` | 건강 신호·체중 추세·대시보드·입력 검증 (순수 함수, 단위 테스트) |
| `src/state/AppData.tsx` | 저장·불러오기(형식 검사), 펫 삭제 시 연쇄 정리, 접종↔일정 연동 |
| `src/screens/` | 5개 탭 + 입력 화면 |
| `src/components/` | 펫 전환, 사진 첨부, 체중 그래프, 공통 카드·폼 |
